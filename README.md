# Homelab

My personal homelab. I initially intended it to merely be a home media server, but as my interest and experience grew in cybersecurity, networking and systems administration, so too did the scope of the project. While there were many joyful and frustrating times (especially DNS but I'll get to that later), I derive great satisfaction from the learning process, and grateful you are taking the time to read through and learn about my journey.

A more professional overview - Personal homelab infrastructure designed, deployed, and maintained as a practical environment for developing systems administration, networking, cybersecurity, and troubleshooting skills.

The environment combines virtualisation, Linux administration, containerised services, internal DNS, reverse proxying, authentication, VPN-based remote access, and service management across multiple hosts.

The repository serves as the configuration source for the environment and documents the architecture, operational decisions, and troubleshooting work involved in project development and maintenance.
